📚 Detective Study Notes

Quick guide to understanding Year 5 Data Handling concepts.

🔁 Mode (Nilai Yang Paling Kerap)

The number or item that appears most frequently in a set of data.

Example: Data set: 3, 7, 7, 5, 7, 4 → Mode = 7 (appears 3 times).

🎯 Median (Nilai Tengah)

The middle value when a data set is ordered from smallest to largest.

Step 1: Arrange data from smallest to largest: 2, 4, 5, 8, 9
Step 2: Find center item → Median = 5.

⚖️ Mean (Min / Purata)

The calculated average. Total sum of all data divided by total count of data.

Formula: Mean = Total Sum ÷ Number of Data
Example: (4 + 6 + 8) ÷ 3 = 18 ÷ 3 → Mean = 6.

📏 Range (Julat)

The difference between the maximum value and minimum value.

Formula: Range = Highest Value − Lowest Value
Example: Data: 3, 8, 15, 6 → 15 − 3 = Range 12.
